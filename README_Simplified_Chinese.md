这是一个**高度拟真的 macOS Sonoma 风格 Web 桌面模拟器**，完全由原生 HTML + CSS + JavaScript 构建，无需任何外部依赖或框架。下面我从技术实现、交互逻辑和功能模块三个维度为你深度总结：

### 1. 核心架构与技术实现
*   **纯前端单页应用**：所有代码集成在一个 `index.html` 文件中，利用 CSS 自定义属性（`var`）统一管理主题风格（菜单高度、圆角、字体）。
*   **毛玻璃效果（Glassmorphism）**：大量使用 `backdrop-filter: blur()` 和 `saturate()` 实现菜单栏、Dock 和窗口的半透明磨砂质感，真实还原 macOS 的视觉层次。
*   **资源加载容错机制**：图标系统会优先尝试加载 `assets/icons/<key>.png` 真实图片，若加载失败则无缝回退到内联的高保真 SVG 矢量图标，确保视觉效果始终在线。
*   **壁纸自适应**：默认使用 CSS 绘制的 Sonoma 风格渐变壁纸，同时会自动检测 `assets/wallpaper.jpg` 并覆盖替换。

### 2. 交互与窗口管理（媲美原生体验）
*   **窗口系统**：
    *   支持**拖拽移动**（通过标题栏）、**四角/边缘缩放**（八个方向）、**最小化**（缩放动画沉入底部）、**最大化**（铺满菜单与 Dock 之间的区域）。
    *   点击窗口自动**聚焦置顶**（`z-index` 动态提升），并高亮边框阴影。
*   **Dock 程序坞**：
    *   **鼠标悬停放大效果**（Magnification）：根据鼠标与图标中心的距离动态计算缩放比例（最大 2.0 倍），平滑过渡。
    *   **智能自动隐藏**：鼠标移出底部边缘时 Dock 自动下滑隐藏，移到底部边缘或悬停在 Dock 上时立即弹出，完全复刻 macOS 行为。
    *   运行中的应用图标下方会显示小黑点指示器。
*   **全局菜单栏**：左上角真实响应点击展开 **Apple 菜单**（包含关于本机、睡眠、重启等模拟选项），右侧显示实时时钟、Wi-Fi/电池等状态图标。

### 3. 预置应用功能解析（不止是 UI 占位）
代码内置了 15+ 款原生风格应用，其中部分具备**真实的交互逻辑**：

| 应用名称 | 功能状态 |
| :--- | :--- |
| **计算器** | 完全可用，支持基础运算（+、-、×、÷）、正负号切换、百分比，逻辑严谨（含连续运算）。 |
| **终端** | 模拟 Bash 环境，支持 `help`、`date`、`whoami`、`echo`、`clear`、`neofetch`、`ls` 等常用命令，输出带高亮。 |
| **备忘录** | 左侧笔记列表可点击切换，右侧文本域内容会动态更新，支持手动输入编辑。 |
| **系统设置** | 提供深色模式、Wi-Fi、蓝牙等**开关组件**（Toggle），且包含“自动隐藏程序坞”的实时控制开关（与主界面联动）。 |
| **启动台** | 全屏毛玻璃界面，以网格展示所有应用图标，点击即可打开对应应用。 |
| **访达 / Safari / 照片** | 布局精美的静态 UI 占位，用于展示 Finder 侧边栏、Safari 地址栏和照片流网格布局。 |

### 4. 细节与用户体验打磨
*   **启动动画**：页面加载时显示带有旋转圆环的黑色开机画面，1 秒后淡出消失，营造系统启动感。
*   **右键菜单**：桌面空白处右键可呼出上下文菜单，快速打开启动台、关于本机或切换 Dock 自动隐藏。
*   **交通灯按钮**：窗口左上角的红（关闭）、黄（最小化）、绿（最大化）按钮悬停时内部会显示对应的符号（×、-、+），精准还原微交互。

### 5. 总结
这不仅仅是一个换皮界面，而是一套**轻量级但完整的桌面操作系统前端框架**。它充分利用了现代 CSS 和浏览器事件模型，在普通网页中实现了**多窗口管理、空间交互（缩放/拖拽/吸附）和局部应用逻辑**。无论是用于技术学习、个人作品集展示，还是作为 Web 应用容器（Shell）的参考实现，都具备极高的完成度和设计水准。你可以在浏览器中直接打开运行，获得近似真实 macOS 的操作乐趣。
